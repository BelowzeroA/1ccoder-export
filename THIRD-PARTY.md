# Сторонние компоненты

Кроме зависимостей из `package.json` и `bun.lock` (их лицензии — в самих пакетах), в приложение и
установщик входят компоненты ниже. Тексты лицензий лежат рядом с компонентами и не переводятся.

| Компонент | Где | Лицензия | Что важно при распространении |
|---|---|---|---|
| **opencode** | весь монорепозиторий | MIT, `LICENSE` в корне | Сохранять уведомление об авторских правах и текст лицензии |
| **1C MCP Toolkit**, изменённый | `packages/desktop/resources/toolkit/MCP_Toolkit.epf` | GPL-3.0, `toolkit/LICENSE` | См. ниже |
| **cc-1c-skills** (навыки для табличных документов MXL) | `packages/desktop/resources/vendor/cc-1c-skills` | MIT, `LICENSE` рядом | Сохранять `LICENSE`; что взято и что изменено — `PROVENANCE.md` |
| **MuPDF** (`mupdf` 1.28.1, растеризация PDF) | зависимость `packages/opencode`; копия `src/util/vendor/mupdf-wasm.wasm` встраивается в исполняемый файл агента | **AGPL-3.0-or-later** | См. ниже |
| **ripgrep** | скачивается при сборке (`scripts/fetch-ripgrep.ts`, проверка SHA-256) в `resources/bin/rg.exe` | MIT / Unlicense | Сохранять уведомление |

## 1C MCP Toolkit

Внешняя обработка 1С от авторов <https://github.com/ROCTUP/1c-mcp-toolkit>, выпуск `v1.8.0`.
Приложение не встраивает её в свой код, а просит платформу 1С открыть её как отдельную программу.

Файл в поставке **изменён**: при создании формы два флажка опасных операций включены по умолчанию
(запись и привилегированный режим без подтверждения), иначе агент не может работать без участия
человека. Изменение целиком — в `toolkit/modifications.diff`, описание — в `toolkit/NOTICE.md`.

Распространяя установщик, вы распространяете изменённую программу под GPL-3.0: прикладывайте
лицензию, `NOTICE.md` и `modifications.diff` (сборка их уже кладёт) и предоставляйте исходный
текст по запросу — это исходники выпуска `v1.8.0` с применённым `modifications.diff`; модули
обработки также извлекаются из самого `.epf` (`v8pack unpack`). Обязанность предоставить исходный
текст по запросу при распространении лежит на распространяющем.

## MuPDF

Пакет `mupdf` распространяется под AGPL-3.0-or-later (или под коммерческой лицензией Artifex).
Его WASM-модуль встроен в исполняемый файл агента, которым пользуется приложение для чтения PDF.
Совместимость такого распространения с вашей моделью лицензирования оцените с юристом; варианты —
коммерческая лицензия Artifex или замена компонента.
